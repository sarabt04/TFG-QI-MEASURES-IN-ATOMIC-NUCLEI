# TFG-QI-MEASURES-IN-ATOMIC-NUCLEI
In this repository there are all the codes I developed to do my undergraduate thesis.
In my thesis I computed entanglement measures and magic measures in 3 nuclei: $^8$Be, $^{20}$Ne, $^{22}$Ne.

In the folder named "data" there are the hamiltonian matrices and the states of each nuclei (in the notation p_2_2 the letter is the shell that represents the valence space, the 1st number the number of protons in the valence space and the 2nd the number of neutrons).

The codes that start with AA have the functions used to compute the quantum information measures.

The codes that start with BB implement these functions to the mentioned nuclei.

The codes that start with CC uses the results found to do comparative plots.
